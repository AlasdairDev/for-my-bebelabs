# Security

This is a static personal site. There is no backend, database, login, analytics,
or server-side code.

- No API keys, tokens, passwords, or private credentials are stored here.
- The tiny secret passcode is a game, not a security control. It is intentionally
  discoverable on the page and does not protect private data. Please do not reuse
  it for anything that matters.
- Photos were resized and stripped of metadata before publishing.
- The only third-party request is Google Fonts.

If you find a problem, open an issue or contact [@AlasdairDev](https://github.com/AlasdairDev).
